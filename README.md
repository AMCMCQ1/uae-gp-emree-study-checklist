# UAE GP Licensing and EMREE Study Checklist

A free checklist for doctors preparing for the UAE General Practitioner licensing MCQ exams and the Emirates Medical Residency Entrance Examination (EMREE).

Maintained by Dr Pravin Kumar, General Practitioner (DHA-licensed), founder of [KnowMed](https://knowmed.life).

## Exams this checklist is for

- DHA Prometric GP exam (Dubai)
- DOH Pearson VUE GP exam (Abu Dhabi)
- MOHAP GP exam
- SHA GP exam
- EMREE

Always confirm dates, fees and eligibility on the authority's own website before you register.

## How to use it

1. Work through the specialties in the order below. The heaviest come first.
2. Inside each specialty, study the high-yield topics first, then moderate, then low-yield.
3. After each topic, answer exam-style MCQs on that topic the same day.
4. Tick the topic only when you can explain why each wrong option is wrong.
5. Sit a timed mock every two weeks and re-open the topics you miss.
